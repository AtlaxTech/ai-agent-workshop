# 笔记架

这里是按主题归档的原始学习笔记架（历史原因保留“每日笔记”目录名，实际不再按日期计划，只按主题批次维护）。

## 项目级维护规则

本页是笔记迁移与维护的权威规则；仓库级执行坐标见 [`../AGENTS.md`](../AGENTS.md)。

1. `01-输入区/` 是临时收集区。用户自行按主题创建分类目录，例如 `01-输入区/Python基础/`。
2. 仅在用户触发维护指令时处理对应主题。Agent 在本目录创建同名主题目录（如已有则复用）。
3. 每次维护在主题目录下创建一个批次目录，格式为 `YYYY-MM-DD_HH-MM-SS/`；本次输入的笔记、代码和相邻资源（如 `note-images/`）原样移动至其中，保留原有相对结构。
4. 原文内容不得修改、重写或覆盖。需要解释、属性、索引或稳定知识时，创建派生页并用相对链接引用归档原文；不得复制原文正文。
5. 迁移后，`01-输入区/` 中保留原主题分类目录及其说明 README，但不留下已维护的文件。输入区应保持干净。
6. 同一主题的后续新增内容在下一次维护时进入新的批次目录；已有归档不可就地混写。需要修正时，追加派生说明或新版本记录，保留历史。
7. 每次维护后更新批次索引、相关双链和引用（确保 Obsidian 图谱连线正确）、必要时新建复习卡片，最后执行 lint 与 checkpoint。

## 双链要求

- 归档批次 ↔ 主题 README ↔ 整理区知识页之间必须互相链接。
- 一律相对路径链接，保证 GitHub 渲染与 Obsidian 知识图谱一致。
