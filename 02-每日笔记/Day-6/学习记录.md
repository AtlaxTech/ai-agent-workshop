# Day 6 — LangGraph 与生产工程基础

## 今日目标

能用 state、node、edge 表达一个可恢复工作流，并理解企业 Agent 为什么需要确定性控制、人工审批、幂等、超时、重试、审计和 trace。

## 时间与任务

- 1h：async、timeout、retry、异常传播和测试复习。
- 1.5h：LangGraph StateGraph、state schema、node、edge、conditional edge。
- 1.5h：checkpoint、memory、streaming、interrupt/HITL。
- 2h：多 Agent supervisor/specialist、串并行、上下文传递和错误隔离；与确定性 workflow 对比。
- 1h：最小审批工作流：读取 → 检查 → 等待批准 → 写操作 → 验证。
- 1h：为拒绝不写、批准只写一次、非法参数和重试添加测试或测试设计。

## 今日必须回答

1. state、node 和 edge 分别负责什么？
2. checkpoint 和普通内存变量有什么区别？
3. 为什么写操作必须幂等？
4. 哪些控制不能只交给 Prompt？
5. 多 Agent 相比一个 Agent 增加了哪些失败面？
