# Day 2 — Python 工程基础与 API

## 今日目标

建立 AI 应用最常见的 Python 工程共同语言：包与依赖、类型提示、Pydantic、HTTP/JSON、同步/异步、FastAPI、异常和 pytest。

## 时间与任务

- 1h：虚拟环境、包、import、`pyproject.toml` 和依赖锁定概念。

- 2h：HTTP 方法、状态码、JSON、FastAPI 路由、请求/响应模型、async/await。
- 2h：最小任务 API：创建任务、读取任务、非法输入返回明确错误；补 3 个 pytest。
- 1h：整理、10 题检查和故障闭环。
