# Day 3 — LLM 调用与结构化输出

## 今日目标

理解 LLM 请求和响应的真实结构，并能用 Python 调用本地 Ollama，获得经过 Pydantic 校验的结构化结果。

## 时间与任务

- 2h：tokenization、embedding、attention、Transformer block、上下文窗口和推理直觉。
- 1h：system/user/assistant/tool messages、temperature、max tokens、stop 与流式输出。
- 2h：Ollama Python SDK / OpenAI-compatible API，请求、超时和异常。
- 2h：同一任务比较自由文本与 JSON Schema/Pydantic 输出；故意诱发一次校验失败并处理。
- 1h：整理、检查题和完整调用链复述。

## 今日必须回答

5. 超时、模型不存在、上下文过长和格式错误分别应在哪里处理？
