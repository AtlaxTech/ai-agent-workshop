# Day 5 — Agent 原理与工具调用

## 今日目标

理解 Agent 是模型、状态、工具和控制循环的组合；能构建一个只有必要自主性的单 Agent，并说明什么时候确定性 workflow 更合适。

## 时间与任务

- 1.5h：Python callable、函数签名、类型提示、JSON Schema 与工具注册。
- 1h：Agent = model + tools + state + loop + termination。
- 1.5h：ReAct、Plan-and-Solve、Reflection 的差异与失败模式。
- 1h：短期 memory、长期 memory、context 与外部知识的区别。
- 2h：用 Ollama 构建带两个白名单只读工具的单 Agent；记录 tool call 和 tool result。
- 1h：加入最大步数、未知工具、参数错误和无工具可用四类失败处理。

## 今日必须回答

1. tool calling 是模型执行了函数，还是模型提出了调用请求？
2. Agent loop 的终止条件有哪些？
3. ReAct、planning 和 reflection 各自增加了什么成本和风险？
4. memory、RAG 和 Chat history 有什么区别？
5. 为什么不是所有任务都应该做成 Agent？
