# 总结与评估

保存 `每日总结/`、`阶段复盘/`、`累积口述/` 和 `能力缺口/`。所有结论都必须来自实际投入、代码、输出、练习答案、复述或实验记录。

模板见 [`../模板/阶段总结模板.md`](../模板/阶段总结模板.md)。

收到 `执行今日学习收尾 Day N` 后，Agent在 `每日总结/Day-N.md` 写收尾报告；收到 `阶段复盘` 后才更新阶段结论。总结不能覆盖原始记录，也不能代替复习卡片。

Day 3 和 Day 7 的累积口述只有在用户执行真实口述或提供逐字稿后才写入 `累积口述/Day-N.md`；评分规则见 [`../00-路线与状态/累积口述验收.md`](../00-路线与状态/累积口述验收.md)。
