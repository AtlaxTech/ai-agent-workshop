## 10:50｜列表最小值、最大值与平均值的高效计算

- 日期时间：2026-08-22 10:50:28 +0800
- 问题类型：代码 / 概念
- 关联主题：Python 列表、内置函数、时间复杂度
- 状态：已确认（不代表用户已掌握）

### 用户原始问题

```python
# 练习一：将用户输入的十个数字，存储到一个列表中，并将列表中的数字进行排序，输出其中的最小值、最大值和平均值
user_input_list = []
user_input_sum = 0
for i in range(10):
    user_input = int(input("Please enter a number: "))
    user_input_list.append(user_input)
    user_input_sum += user_input
user_input_list.sort()
user_input_min = user_input_list[0]
user_input_max = user_input_list[-1]
user_input_average = user_input_sum / len(user_input_list)
print("—————最终结果—————")
print(f"用户输入的最小值：{user_input_min}")
print(f"用户输入的最大值：{user_input_max}")
print(f"用户输入的平均值：{user_input_average}")
```

我想知道就单从这个练习而言，还有没有更加高效的方式计算列表平均值和获取最大最小值了？

### Agent 实际回答

有。如果你最终只需要最小值、最大值和平均值，最简洁的写法是直接使用 `min()`、`max()`、`sum()` 和 `len()`，不必排序：

```python
numbers = []

for _ in range(10):
    number = int(input("Please enter a number: "))
    numbers.append(number)

minimum = min(numbers)
maximum = max(numbers)
average = sum(numbers) / len(numbers)

print("—————最终结果—————")
print(f"用户输入的最小值：{minimum}")
print(f"用户输入的最大值：{maximum}")
print(f"用户输入的平均值：{average}")
```

直觉上，为了找最大和最小值，只要把列表从头到尾看一遍就够了；没必要先确定所有数字之间的先后次序。

准确地说：

- 你现在的 `sort()` 通常需要 `O(n log n)` 时间。
- `min()`、`max()` 和 `sum()` 各扫描一次列表，总体仍是 `O(n)` 时间。
- 对 10 个数字来说，性能差异几乎可以忽略；这种写法的主要优点是意图清楚、不做无需的排序。

不过，题目明确说了“将列表中的数字进行排序”。如果“排序后的列表”本身也是练习要求，那么你现在的处理很合理：

```python
numbers.sort()
minimum = numbers[0]
maximum = numbers[-1]
average = sum(numbers) / len(numbers)
```

排序完成后，用首尾索引取最小值和最大值都是 `O(1)`。也就是说，你原代码并没有明显问题；是否去掉排序，取决于“排序”是不是必须的输出或练习目标。

如果你追求严格意义上的“只扫描一遍”，还可以在接收输入时同时维护总和、最小值和最大值：

```python
numbers = []
total = 0
minimum = None
maximum = None

for _ in range(10):
    number = int(input("Please enter a number: "))
    numbers.append(number)
    total += number

    if minimum is None or number < minimum:
        minimum = number
    if maximum is None or number > maximum:
        maximum = number

average = total / len(numbers)
```

这也是 `O(n)`，而且计算统计值只需一轮。但它的代码更长；对这道题，我会优先选择 `min()`、`max()` 和 `sum() / len()`
的版本。你现在在循环中累加 `user_input_sum` 也完全正确，它已经避免了之后再求和的一次扫描。

常见误区：

- 不要为了取最大/最小值就默认必须排序。
- 空列表不能直接使用 `min()`、`max()`，也不能用 `sum(numbers) / len(numbers)`；但这道题固定输入 10 次，所以不会为空。
- 不要把变量命名为 `min`、`max` 或 `sum`，否则会遮蔽 Python 的同名内置函数。

理解检查：如果题目改成“输入 100 万个数，只输出最大值”，你能说明为什么 `max(numbers)` 比“先 `sort()` 再取 `numbers[-1]`
”更合适吗？
