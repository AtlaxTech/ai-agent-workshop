# if 语句: 只有满足指定条件，才会执行对应的代码逻辑
判断语句的结果必须是布尔类型（True 或 False）
注意：在python中是通过缩进来描述代码归属的，归属于if代码块的语句，需要在前方缩进4个空格

```python
    # 例如：判断一个数字是否大于 0
    num = 10
    if num > 0:
        print("num 大于 0")
    else:
        print("num 不大于 0")
```
