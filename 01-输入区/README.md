# 输入区

存放未经整理的原始输入：课程记录、文档摘录、临时理解、问题、报错和实验输出。

建议按 `Day-N/` 建目录。Agent 可以读取和引用，但整理时不得覆盖、改写或删除原始内容。

你不必强迫自己先分类。也可以在每日笔记、练习或项目目录直接输入；当你说 `整理未归档输入` 或 `执行今日学习收尾 Day N` 时，Agent会根据处理游标发现新增内容，再决定保留原位、移动原始材料或建立派生知识页。

学习问答不等待收尾：若当前 Day 尚未确定，Agent在回答后立即把问题原文和完整回答追加到 `问题与回答/YYYY-MM-DD.md`。确定 Day 后则直接写入对应每日笔记。
