# 输入区

存放未经维护的原始输入：课程记录、文档摘录、临时理解、问题、报错和实验输出。

建议直接按主题建目录，例如 `Python基础/`、`RAG/`、`Agent/`。Agent 可以读取和引用，但归档前不得覆盖、改写或删除原始内容。

你不必强迫自己先分类。也可以在其他区域直接记录；当你说 `维护输入区` 或 `维护输入区：<主题>` 时，Agent 会根据处理游标发现新增内容，再决定保留原位、移动原始材料到笔记架还是建立派生知识页。

学习问答不等待维护：用 `回答问题：...` 提问时，Agent 会立即把问题原文和完整回答追加到 `问题与回答/YYYY-MM-DD.md`，下次维护随批次归档。练习区和项目区同样可以按主题自由写入。
