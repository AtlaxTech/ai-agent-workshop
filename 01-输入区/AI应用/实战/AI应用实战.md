## Streamlit

开源的 python 库，专门为数据工程师以及机器学习工程师设计，用来快速基于python代码构建交互式web网站
官方网站：https://streamlit.io/
使用教程：

1. 安装streamlit：pip install streamlit
2. 在python中引入streamlit模块
3. 基于streamlit中提供的API构建Web应用
4. 运行程序：streamlit run xxx.py
