# Python 基础语法与核心结构

## 一句话结论

Python 基础语法的目标不是背诵容器或语句，而是能把输入、数据、控制流和行为组织成可读、可验证的程序；在 Agent 工程中，它们共同构成状态、工具参数和失败处理的基础。

## 核心结构

| 结构 | 适合解决的问题 | Agent 工程中的典型用途 |
|---|---|---|
| 变量与基本类型 | 给值一个清晰名称并表达数据含义 | 请求 ID、模型响应、开关与配置 |
| `list` / `tuple` | 有序项目；tuple 用于不应重绑定的固定结构 | 对话消息、工具列表、坐标或返回多个值 |
| `set` | 去重与成员判断，不保证顺序 | 白名单工具名、已处理文档 ID |
| `dict` | 按键访问结构化数据 | JSON 请求、Agent state、工具参数 |
| 条件与循环 | 对不同输入走不同路径、处理多个项目 | 路由、重试、批量处理、终止条件 |
| 函数与类 | 封装可重用行为与数据边界 | 工具函数、服务、状态对象、测试对象 |

## 最小示例

```python
def select_enabled_tools(requested: list[str], allowed: set[str]) -> list[str]:
    return [name for name in requested if name in allowed]

allowed_tools = {"search_orders", "get_customer"}
requested_tools = ["get_customer", "delete_all"]

print(select_enabled_tools(requested_tools, allowed_tools))
# ['get_customer']
```

这个例子同时使用了列表、集合、条件、循环、函数和类型提示：模型或用户提出的名称不等于被授权执行的工具。

## 常见误区与更正

- Python 的变量是名称到对象的绑定；“动态类型”不代表工程代码可以随意改变数据含义。
- 字符串不可变，频繁使用 `+` 不会破坏字符串，只是可能产生不必要的新对象；多段拼接优先考虑 `"".join(...)`。
- 切片的结束位置是排他的；省略结束位置等价于到序列末尾，而不是 `-1`。
- 空集合应使用 `set()`，`{}` 是空字典。
- 元组的不可变只限制元组自身的绑定；其中如果放了可变对象，该对象仍可被修改。
- `dict` 的键必须可哈希，通常使用字符串、数字或元组；列表、集合和字典不能作为键。
- `getpass` 只控制终端回显，不会加密输入；敏感信息也不能写入笔记、日志或快照。
