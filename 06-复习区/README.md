# 复习区

这里运行多轮主动回忆与间隔复习，不复制整理笔记，也不把一次阅读视为掌握。

## 结构

- `复习索引.json`：所有卡片的排期、阶段、历史和状态事实源。
- `知识卡片/`：仍在学习周期中的原子卡片。
- `今日复习/`：按指令生成的到期队列快照。
- `复习记录/`：用户回答、提示、信心、评级与纠错。
- `已掌握/`：满足多轮稳定回忆条件后由工具移动的卡片。
- `错题与薄弱项.md`：在出现真实错误后创建。
- `口述提纲/`：3–5 分钟脱稿讲解提纲。

## 默认周期

新卡片首次安排在次日。后续依据表现进入 3、7、14、30 天阶段；答错会回到短间隔。至少完成五轮复习并在最高阶段连续稳定，才能归档。

默认每日复习预算为 25 分钟，每张卡按 2 分钟估算。系统先安排求职/项目关键项，再考虑历史失败次数、逾期程度和记忆阶段。超出预算的卡片不会改期或消失，而会保留为到期项等待下一次生成队列。

## 指令

- `生成今日复习任务`
- `开始今日复习`
- `完成今日复习并重新排期`
- `检查逾期复习`

日期、历史和归档条件由 `scripts/learning_ops.py` 计算，Agent不得凭印象直接修改。
