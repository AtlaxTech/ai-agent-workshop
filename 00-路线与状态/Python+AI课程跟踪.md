## 跟踪原则

这门课是本阶段唯一 Python 视频主线，但“看完”与“掌握”分开记录：

1. 熟悉内容用 1.75–2 倍速，并通过一个代码预测或变体确认；能通过才允许标记“快速通过”。
2. 新内容和 AI 应用用 1.25–1.5 倍速，必须亲自运行课程代码并修改至少一个输入、参数或失败路径。
3. 仅播放、复制代码或看懂屏幕不算完成；每个章节至少留下一个代码/输出/错误/口述证据链接。
4. 跳过必须写原因：环境已完成、已有证据、与岗位低相关或暂缓，不能无记录跳过。
5. 执行「维护输入区」时只根据真实观看与运行记录更新本页；Agent不得根据计划批量勾选。
