## 本周不采用

- 标题承诺“七天从小白到大神”但缺少可信维护者、代码或课程目录的合集。
- 只背 Agent 面试题、不要求运行代码和解释失败的八股课程。
- 同时学习 LangGraph、CrewAI、AutoGen、Dify、n8n、LlamaIndex 多套框架。
- 需要付费 API、云 GPU 或付费托管才能完成的课程。
- 直接进入微调、强化学习、CUDA、vLLM 性能内核的内容。

## 零预算与本机策略

- 所有实验优先使用已经安装的 Ollama 和现有本地模型。
- 文本学习和普通 Python 不需要 GPU。
- 不为了跟随课程购买 API；课程代码若强依赖云 API，改写为 Ollama/OpenAI-compatible 本地端点，不能改时只学概念。
- M4/32GB 足够完成本周小规模 RAG、工具调用和 LangGraph 实验；不在本周尝试训练大模型。
