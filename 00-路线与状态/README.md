# 路线与状态

这里保存学习系统的慢变状态文件。只根据用户提供的真实证据更新，不得把计划投入写成实际投入。

## 学习状态

- [`当前状态.md`](当前状态.md) — 当前阶段与下一个检查点。
- [`学习进度.md`](学习进度.md) — 按主题的真实进度台账。
- [`Python+AI课程跟踪.md`](Python+AI课程跟踪.md) — 指定 B 站课程的分集地图、真实进度和应用证据。
- [`学习资源.md`](学习资源.md) — 按主题整理的课程与资料清单。

## 系统机制

- [`学习系统.md`](学习系统.md) — 输入识别、Ingest/Query/Lint、复习状态机与指令说明。
- `学习系统配置.json` — 扫描范围、复习间隔、每日负荷和归档阈值。
- `输入处理状态.json` — 上次已处理文件的确定性游标。

调度工具位于 `scripts/learning_ops.py`（scan / checkpoint / next-id / register / due / record / lint）。完整协作规则见 [`../AGENTS.md`](../AGENTS.md)。
