# Applied AI Agent Engineering 一周基础强化

这是 7 天 × 8 小时的完整学习入口。当前只补 Python、LLM 应用、RAG、Agent 与工程可靠性基础，不推进 AtlasOps 新功能、简历、LinkedIn 或投递。

## 使用顺序

1. 先读 [`一周学习路线图.md`](一周学习路线图.md)。
2. 当天只打开对应 Day 笔记和 [`学习资源.md`](学习资源.md)。
3. 学习过程中把原始材料放入 `01-输入区/Day-N/`，把当天理解、代码、错误和问题写入 `02-每日笔记/Day-N/学习记录.md`。
4. 每日结束仅在收到指令后，按 [`每日整理与验收流程.md`](每日整理与验收流程.md) 整理。
5. 验收后更新 [`学习进度.md`](学习进度.md) 和 [`当前状态.md`](当前状态.md)。

## 本周完成标准

- 能阅读并解释一段包含类型提示、Pydantic、异常和测试的 Python 代码。
- 能用 Python 调用本地 Ollama，理解 messages、token、temperature、structured output 和 tool calling。
- 能画出 RAG 从数据到评测的完整链路，并解释至少五种降低幻觉措施。
- 能区分确定性 workflow、单 Agent、多 Agent，说明 ReAct、planning、reflection、memory 和 HITL。
- 能解释 LangGraph 的 state、node、edge、checkpoint 和人工审批。
- 能只读进入 AtlasOps，根据 AGENTS/Handoff 定位工作流与测试，并完成一次中文脱稿讲解。

完成本周不等于掌握 Applied AI Engineering 全部知识；它代表已经建立继续读项目、做实验和准备面试所需的最小共同语言。
